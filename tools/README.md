# tools

Вспомогательные инструменты: стендовые тесты и скрипты для ПК.

| Папка | Содержимое |
|---|---|
| `ak80-gui/` | пульт стенда AK80-64 на ПК: кнопки, графики телеметрии, статистика ходов, запись CSV (Python, PySide6) |
| `ak80-mega-test/` | стендовый тест и интерактивная консоль AK80-64 на Arduino Mega + MCP2515 (PlatformIO, Unity) |
| `can/` | работа с AK80-64 с ПК через USB-CAN адаптер: настройка CAN ID, проверка моторов, калибровка нуля |
| `log-analysis/` | разбор логов прошивки и стендовых испытаний, графики момента и положения |

Зависимости каждого Python-инструмента перечисляются в `requirements.txt` рядом с ним.
Виртуальное окружение (`.venv/`) в репозиторий не коммитится.
