# tools

Вспомогательные скрипты для ПК (Python).

| Папка | Содержимое |
|---|---|
| `can/` | работа с AK80-64 с ПК через USB-CAN адаптер: настройка CAN ID, проверка моторов, калибровка нуля |
| `log-analysis/` | разбор логов прошивки и стендовых испытаний, графики момента и положения |

Зависимости каждого инструмента перечисляются в `requirements.txt` рядом с ним.
Виртуальное окружение (`.venv/`) в репозиторий не коммитится.
