# ak80-gui

Пульт стенда AK80-64 на ПК: окно с кнопками, графиками и журналом поверх
интерактивной консоли [`ak80-mega-test`](../ak80-mega-test/README.md).
Мотором по-прежнему управляет Mega, пульт только отправляет текстовые команды
консоли и разбирает её вывод. Поэтому любую команду можно набрать и вручную.

## Что нужно

- Arduino Mega с прошивкой консоли из `tools/ak80-mega-test`. После
  `pio test` в Mega остаётся тестовая прошивка, консоль нужно прошить заново:
  `pio run -e mega -t upload`.
- Python 3.10 или новее (проверено на 3.12).
- Пользователь в группе `dialout`, иначе порт не откроется.

## Установка

```bash
cd tools/ak80-gui
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Окружение занимает около 750 МБ, в основном PySide6. Папка `.venv/` в git
не попадает.

## Запуск

```bash
cd tools/ak80-gui
.venv/bin/python -m ak80_gui                      # порт выбирается в окне
.venv/bin/python -m ak80_gui --port /dev/ttyACM0  # подключиться сразу
```

Порт должен быть свободен: закройте `pio device monitor`. Пока пульт
подключён, Mega не прошивается.

При подключении Mega перезагружается и выводит мотор из режима управления,
вал свободен. Пульт дожидается приветствия консоли, запрашивает настройки (`s`)
и включает телеметрию 50 Гц. При отключении и при закрытии окна пульт
освобождает вал (`x`) и выводит мотор из режима управления (`off`).

## Окно

Левая панель:

| Блок | Что делает | Команды консоли |
|---|---|---|
| СТОП (Esc) | освободить вал, нулевой момент. Esc работает в любом месте окна | `x` |
| Состояние мотора | режим, позиция, уставка, скорость, момент, температура и код ошибки из телеметрии | — |
| Режим управления | Включить: вал свободен. Держать: держать текущую позицию. Выключить: выйти из режима | `on`, `hold`, `off` |
| Позиция | ход в абсолютную позицию, поворот на угол от уставки, быстрые кнопки ±10°, ±90°, ±180° | `m`, `r` |
| Вращение | постоянная скорость. «Плавно стоп» снижает её до нуля и держит позицию | `v`, `v 0` |
| Цикл туда и обратно | N раз на угол от текущей позиции и обратно, полоса показывает номер хода | `c` |
| Настройки движения | «Применить» отправляет только изменённые значения. «Задать ноль…» спрашивает подтверждение | `speed`, `accel`, `kp`, `kd`, `maxt`, `zero` |

Значения в настройках при подключении берутся из Mega, пределы полей те же,
что в консоли.

Справа сверху графики позиции (уставка пунктиром), скорости и момента. Окно
графиков 5–60 с, частота телеметрии 10–100 Гц. «Пауза графиков» замораживает
картинку, данные при этом продолжают приходить и записываться. Вертикальный
масштаб меняется колёсиком мыши, кнопка «A» в углу графика возвращает
автомасштаб.

Справа снизу две вкладки:

- «Журнал»: весь вывод консоли и отправленные команды. Предупреждения (строки
  с `!`) выделены красным и дублируются в строке состояния. Строка ввода
  отправляет любую команду консоли по Enter, стрелки ↑ и ↓ листают историю.
- «Ходы»: таблица ходов из сообщений `Ход …` и сводка: средняя ошибка в конце
  хода, СКО, наибольшая ошибка, наибольшее отставание и пик момента.
  «Статистика контроллера» запрашивает `stats`, «Очистить» очищает таблицу и
  сбрасывает статистику в Mega (`stats reset`), «Сохранить CSV…» сохраняет
  таблицу.

В строке состояния справа порт, фактическая частота телеметрии и число
записанных строк. «нет телеметрии» значит, что строк не было дольше 1,5 с.

## Запись данных

Флажок «Записывать телеметрию в CSV» пишет файл
`logs/telemetry-ГГГГММДД-ЧЧММСС.csv`:

```
pc_time,t_ms,mode,p_ref_deg,pos_deg,vel_dps,torque_nm,temp_c,error
```

`pc_time` — время ПК, остальные столбцы как в телеметрии консоли (раздел
«Телеметрия» в README `ak80-mega-test`). Таблица ходов сохраняется по
умолчанию в `logs/moves-ГГГГММДД-ЧЧММСС.csv` со столбцами
`leg,legs,from_deg,to_deg,duration_s,error_deg,lag_deg,torque_peak_nm`.
Папка `logs/` в git не попадает.

Телеметрия идёт и тогда, когда мотор не в режиме управления (режим O). Мотор
в этом режиме не опрашивается, поэтому позиция, скорость и момент — последние
известные. Если мотор после включения Mega ещё ни разу не ответил, там нули,
а в журнале на `s` будет «Ответов от мотора ещё не было».

## Безопасность

- Своих защит у пульта нет. Пределы позиции, ограничение момента и аварийные
  остановки работают в прошивке консоли (раздел «Защита» в README
  `ak80-mega-test`).
- СТОП и Esc освобождают вал, но мотор остаётся в режиме управления.
- Если пульт завис или закрылся аварийно, Mega продолжает выполнять последнюю
  команду, например вращение. Выключите ЛБП или подключитесь заново: при
  подключении Mega перезагружается и освобождает вал.

## Если не работает

| Признак | Что проверить |
|---|---|
| «Порт не открылся: … Permission denied» | группа `dialout`: `sudo usermod -aG dialout $USER`, затем выйти из системы и войти снова |
| Журнал пустой или строки приходят обрывками | порт читает ещё одна программа, обычно `pio device monitor`: `fuser -v /dev/ttyACM0` |
| Нет приветствия «AK80-64, консоль стенда» | в Mega тестовая прошивка после `pio test`, прошить консоль |
| «Мотор не отвечает: питание, kMotorId, test_bus_scan» | включён ли ЛБП, дальше раздел «Если не работает» в README `ak80-mega-test` |
| «нет телеметрии», пока мотор не в режиме управления | старая прошивка консоли, она шлёт телеметрию только в режиме управления; прошить заново |
| Окно не открывается: `GLib-GIO-ERROR … does not contain a key named 'antialiasing'` | запуск из терминала VS Code, установленного через snap: он передаёт программам свои схемы GNOME. Пульт сам убирает эти переменные (`snap_env.py`); если ошибка всё же появилась, запустить из обычного терминала (Ctrl+Alt+T) |

## Тесты

```bash
cd tools/ak80-gui
.venv/bin/python -m pytest
```

Тесты проверяют разбор вывода консоли и сборку команд на строках из прогона на
стенде, железо не нужно.

## Устройство

| Файл | Что внутри |
|---|---|
| `ak80_gui/protocol.py` | разбор строк консоли и сборка команд, без ввода-вывода |
| `ak80_gui/link.py` | порт USB-Serial, чтение в отдельном потоке |
| `ak80_gui/data.py` | буфер телеметрии для графиков, сводка по ходам, запись CSV |
| `ak80_gui/window.py` | главное окно |
| `ak80_gui/snap_env.py` | очистка окружения терминала VS Code из snap перед запуском Qt |

Пульт узнаёт ходы, настройки и режим по тексту сообщений консоли. Если в
`src/main.cpp` меняется их формат, нужно поправить регулярные выражения в
`protocol.py` и тесты.
