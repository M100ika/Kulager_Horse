# control

Пользовательская часть: через неё всадник или оператор отдаёт команды модулю.

| Папка | Содержимое |
|---|---|
| `mobile-app/` | приложение на телефоне, связь с модулем по BLE |

Фреймворк приложения ещё не выбран (Flutter, React Native или нативный Android).
Решение фиксируется в `docs/architecture/adr/`.

BLE-протокол между приложением и прошивкой описан в `docs/interfaces/`.
Приложение и прошивка должны реализовывать одну и ту же версию протокола.
