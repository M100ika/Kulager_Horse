# firmware

Прошивка ESP32: управление двумя AK80-64 по CAN, связь с телефоном по BLE,
функции безопасности. Сборка: PlatformIO.

| Папка | Содержимое |
|---|---|
| `src/` | `main.cpp` и задачи верхнего уровня |
| `include/` | общие заголовки и конфигурация (CAN ID моторов, ограничения, таймауты) |
| `lib/ak_motor/` | драйвер AK80-64 по CAN (TWAI): кодирование команд, разбор ответов, режимы управления |
| `lib/ble_link/` | BLE GATT-сервер: приём команд с телефона, отправка телеметрии |
| `lib/safety/` | сторожевой таймер, контроль связи, ограничения момента, аварийный переход в нулевой момент |
| `test/` | unit-тесты; логика без железа гоняется в окружении `native` |

## Принципы

- `safety` не зависит от `ble_link`: потеря связи обнаруживается по таймауту,
  а не по событию от BLE-стека.
- Ограничения (момент, скорость, ход) хранятся в одном месте в `include/`
  и соответствуют `docs/safety/limits.md`.
- Протоколы описаны в `docs/interfaces/`. Код следует документу, а не наоборот.

## Инициализация

Проект PlatformIO ещё не создан: сначала нужно выбрать плату и фреймворк.
После выбора, например:

```bash
cd firmware
pio project init --board esp32-s3-devkitc-1
```
