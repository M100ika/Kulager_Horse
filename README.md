# Kulager_Horse

Модуль управления лошадью. Крепится перед седлом и управляет уздечкой (поводом)
с помощью двух мотор-редукторов CubeMars AK80-64 Kv80. Моторами по CAN управляет
микроконтроллер ESP32, команды приходят с приложения на телефоне по BLE.

```
Телефон ──BLE──▶ ESP32 ──CAN──▶ AK80-64 (левый)  ──▶ левый повод
                   │      └───▶ AK80-64 (правый) ──▶ правый повод
                   │
     аварийный выключатель (обесточивает моторы)        батарея
```

## Пульт мотора на стенде

Сейчас мотор AK80-64 управляется со стенда: Arduino Mega с модулем MCP2515
и пульт на ПК [`tools/ak80-gui`](tools/ak80-gui/README.md) с кнопками,
графиками, таблицей ходов и записью телеметрии в CSV. Переход на ESP32 —
следующий этап.

Что нужно:

- Mega с MCP2515 и мотором, подключённые по схеме из
  [`tools/ak80-mega-test`](tools/ak80-mega-test/README.md);
- [PlatformIO](https://platformio.org/) (команда `pio`) и Python 3.10 или новее;
- в Linux пользователь в группе `dialout`:
  `sudo usermod -aG dialout $USER`, затем выйти из системы и войти снова.

Перед включением проверьте: мотор жёстко закреплён, на валу нет повода
и нагрузки, у лабораторного блока питания ограничение тока 2–3 А,
выключатель питания под рукой.

```bash
# 1. Прошить в Mega консоль. Один раз; после pio test — заново
cd tools/ak80-mega-test
pio run -e mega -t upload

# 2. Установить пульт. Один раз, окружение занимает около 750 МБ
cd ../ak80-gui
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3. Запустить пульт
.venv/bin/python -m ak80_gui
```

В окне выберите порт Mega (в Linux обычно `/dev/ttyACM0`) и нажмите
«Подключить». Mega перезагрузится, мотор выйдет из режима управления, вал
будет свободен. Кнопка СТОП и клавиша Esc освобождают вал, в крайнем случае
выключите блок питания. Порт должен быть свободен: закройте
`pio device monitor` и не прошивайте Mega, пока пульт подключён.

Пульт проверен на Linux (Ubuntu). На Windows вместо `.venv/bin/` пишется
`.venv\Scripts\`, порт называется `COM3` или похоже; там пульт ещё
не запускали. Описание окна, запись данных и решение проблем —
в [README пульта](tools/ak80-gui/README.md).

## Правила

Перед началом работы прочитайте [`CONTRIBUTING.md`](CONTRIBUTING.md): ветки,
документирование, pull request, файлы, использование ИИ. Коротко:

- в `main` напрямую не пушить, работать в своей ветке, в `main` — только через
  pull request после согласования с @M100ika;
- всё сделанное записывать в коммиты и журнал ветки в [`docs/worklog/`](docs/worklog/);
- не мусорить: никаких черновиков, временных файлов, сборок и файлов ИИ-инструментов;
- никаких испытаний на лошади без пройденных стендовых испытаний и проверки
  требований из [`docs/safety/`](docs/safety/).
