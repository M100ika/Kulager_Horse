# Kulager

Модуль управления лошадью. Крепится перед седлом и управляет уздечкой (поводом)
с помощью двух мотор-редукторов CubeMars AK80-64 Kv80. Моторами по CAN управляет
микроконтроллер ESP32, команды приходят с приложения на телефоне по BLE.

```
Телефон ──BLE──▶ ESP32 ──CAN──▶ AK80-64 (левый)  ──▶ левый повод
                   │      └───▶ AK80-64 (правый) ──▶ правый повод
                   │
     аварийный выключатель (обесточивает моторы)        батарея
```

## Карта репозитория

| Папка | Что внутри | Инструмент |
|---|---|---|
| [`docs/`](docs/) | требования, архитектура, безопасность, протоколы, даташиты, испытания | Markdown |
| [`mechanical/`](mechanical/) | корпус, привод повода, крепление к седлу, чертежи, расчёты | FreeCAD |
| [`electrical/`](electrical/) | схема и плата, жгуты, питание, BOM, Gerber | KiCad |
| [`firmware/`](firmware/) | прошивка ESP32: драйвер моторов, BLE, безопасность | PlatformIO |
| [`control/`](control/) | приложение на телефоне | будет выбран |
| [`tools/`](tools/) | скрипты для ПК: работа с моторами по CAN, анализ логов | Python |

## Правила

- Имена файлов и папок латиницей, в `kebab-case`, без пробелов. Документация на русском.
- Исходники лежат отдельно от выходных файлов: `cad/` и `kicad/` против `exports/`,
  `drawings/` и `fabrication/`. Выходные файлы обновляются при выпуске ревизии.
- Ревизии отмечаются git-тегами: `mech-rA`, `pcb-rA`, `fw-v0.1.0`.
- Значимые инженерные решения записываются в [`docs/architecture/adr/`](docs/architecture/adr/).
- Никаких испытаний на лошади без пройденных стендовых испытаний и проверки
  требований из [`docs/safety/`](docs/safety/).
