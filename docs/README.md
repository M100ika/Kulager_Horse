# docs

Проектная документация.

| Папка | Содержимое |
|---|---|
| `requirements/` | требования: усилие и ход повода, скорость реакции, масса, время работы от батареи, условия эксплуатации |
| `architecture/` | блок-схема системы, распределение функций между узлами |
| `architecture/adr/` | журнал решений (Architecture Decision Records) |
| `safety/` | анализ отказов (FMEA), ограничения момента, аварийная остановка, поведение при потере связи |
| `interfaces/` | CAN-протокол AK80-64, BLE-протокол модуль ↔ телефон, распиновка разъёмов |
| `datasheets/` | даташиты и мануалы: CubeMars AK80-64, ESP32, CAN-трансивер |
| `testing/` | протоколы и отчёты испытаний: стенд → манекен → лошадь |
| `worklog/` | журналы работы веток: что сделано, проверено, что дальше |

## Журнал решений (ADR)

Одно решение = один файл `NNNN-kratkoe-nazvanie.md`, например
`0001-esp32-kak-upravlyayushchiy-mk.md`. В файле: контекст, рассмотренные
варианты, принятое решение, последствия. Принятые ADR не переписываются;
если решение меняется, пишется новый ADR со ссылкой на старый.
