# safety

Требования безопасности для лошади и всадника. Этот раздел нужно заполнить
и согласовать до написания прошивки и до первых испытаний.

## Базовые принципы (черновик)

1. **Безопасное состояние — отпущенный повод.** При любой неисправности моторы
   переходят в нулевой момент, повод провисает.
2. **Потеря связи.** Если команды с телефона не приходят дольше заданного
   таймаута, модуль переходит в безопасное состояние.
3. **Ограничение момента.** AK80-64 развивает момент в десятки Н·м, это намного
   больше нужного для повода. Максимальное усилие ограничивается в прошивке и
   проверяется на стенде. Предел обосновывается в `docs/requirements/`.
4. **Аппаратный аварийный стоп.** Выключатель на модуле физически обесточивает
   моторы и не зависит от прошивки.
5. **Батарея.** При разряде ниже порога модуль заранее предупреждает и плавно
   отпускает повод, а не отключается внезапно.
6. **Сторожевой таймер.** Зависание прошивки приводит к безопасному состоянию.
