# safety

Требования безопасности для лошади и всадника. Этот раздел нужно заполнить
и согласовать до написания прошивки и до первых испытаний.

## Базовые принципы (черновик)

1. **Целевое безопасное состояние — освобождённая тяговая ветвь.** Нулевой момент
   и снятие питания AK80-64 не гарантируют отпускание из-за редуктора. Требуется
   механическое размыкание и проверка остаточного усилия, в том числе без питания.
2. **Потеря связи.** Если команды с телефона не приходят дольше заданного
   таймаута, модуль переходит в безопасное состояние.
3. **Ограничение момента.** AK80-64 развивает момент в десятки Н·м, это намного
   больше нужного для повода. Усилие ограничивается по отдельным датчикам силы
   и независимой механической защитой, затем проверяется на стенде. Предел для
   животного пока не определён; стендовые значения нельзя переносить на лошадь.
4. **Аппаратный аварийный стоп.** Выключатель снимает разрешение муфт и силового
   питания независимо от прошивки. Отдельный ручной сброс работает под нагрузкой.
5. **Батарея.** При разряде ниже порога модуль заранее предупреждает и плавно
   отпускает повод, а не отключается внезапно.
6. **Сторожевой таймер.** Зависание прошивки приводит к безопасному состоянию.
