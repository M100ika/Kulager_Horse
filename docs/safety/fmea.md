# Предварительный анализ отказов rA

Ни одна мера в таблице не считается подтверждённой существующим CAD.

| Отказ | Последствие | Предлагаемая мера и проверка |
|---|---|---|
| BLE потерян, приложение закрыто | Застывший запрос | Локальное истечение команды; размыкание обоих каналов; новый взвод |
| ESP32 завис, выход GPIO залип | Продолжение тяги | Независимый watchdog снимает аппаратное разрешение; инъекция отказа |
| CAN bus-off/задержки | Мотор удерживает прежнее состояние | Проверка свежести; муфты снимаются вне CAN |
| Драйвер выдаёт большой момент | Резкий рывок | Ограничитель, рассчитанный на входной отказ; независимый контроль силы |
| Муфта не разомкнулась/сварилась | Редуктор удерживает ленту | Контроль размыкания; отдельный ручной размыкатель после направляющей |
| Барабан или направляющая заклинили | Отпускание невозможно | Защита от шерсти/грязи; ручное размыкание тяговой ветви за узлом |
| Датчик силы оборван/замкнут/застыл | Ошибочная команда | Контроль диапазона и правдоподобия; диагностика двух каналов; механический предел |
| Ограничитель проскользнул | Моторный энкодер потерял длину | Энкодер на самом барабане; повторный взвод после диагностики |
| BMS выключила батарею/обрыв жгута | Нельзя отдать команду отпускания | Муфты отпускают без питания; проверка остаточной силы |
| Контактор сварился | Моторная шина остаётся активной | Муфты имеют независимый путь отключения; контроль состояния |
| Стропа/болт ослаб | Модуль падает или поворачивается | Четыре силовые опоры, стопорение, контроль перед работой, независимое удержание |
| Вода, шерсть, перегрев | КЗ/заедание/ожог | Кожух, вводы, температурный контроль; проверка среды без животного |
| Ручной сброс породил петлю | Зацеп за животное/снаряжение | Укладка и ограничение свободного конца; натурный макет |
| Связь восстановилась | Неожиданный рывок | Латч отказа и явный новый взвод при нейтральной команде |

Отпущенная тяга уменьшает воздействие механизма, но сама по себе не гарантирует
остановку или управляемость лошади. Независимые ручные поводья и оператор нужны
даже при полностью исправной электронике.
