# Управление модулем rA — проект, не реализованная прошивка

Каналы левого и правого повода независимы. Телефон задаёт запрос на ограниченное
натяжение, ESP32 замыкает контур по датчикам усилия, а драйверы получают команды
по CAN. Реакция лошади на натяжение не является детерминированной командой
«повернуть/остановиться»; интерфейс должен показывать запросы левого/правого
канала, измеренную силу и состояние разрешения, без обещания автопилота.

Состояния: `DISARMED → SELF_TEST → READY → ACTIVE`; при неисправности
`RELEASE → FAULT_LATCHED`. После включения питания и восстановления BLE всегда
требуется новый явный взвод при нейтральном запросе. Старая команда не возобновляется.
В SELF_TEST проверить датчики, согласованность энкодеров, связь, батарею и
обратную связь муфт. Муфты включать только при выполнении всех условий READY.

Начальные значения **только для стенда с грузом/пружиной**:

| Параметр | Стартовая гипотеза |
|---|---:|
| Максимальное натяжение каждого канала | 5 Н |
| Максимальный дополнительный ход | 80 мм |
| Скорость изменения длины | 10 мм/с |
| Скорость нарастания заданной силы | 2 Н/с |
| Период команды BLE | 50 мс |
| Истечение команды | 200 мс |
| Устаревшие CAN/силовые измерения | 50 мс |
| Локальный цикл регулирования | 5 мс, проверить задержку реального ADC |

Это не одобренные пределы для животного и не гарантированные времена системы.
Аппаратный порог силы задаётся после выбора датчика и измерения разброса защиты.
При превышении измеренной силы, неисправности датчика, достижении хода, сбое CAN,
watchdog, падении разрешения или потере BLE разомкнуть оба канала. Команда
нулевого момента и управляемая отдача могут сопровождать отключение, но не
являются необходимым условием срабатывания механического освобождения.

BLE-пакет: версия, ID текущей сессии, монотонный sequence, запрос двух каналов,
признак удержания кнопки. Возраст считать по локальному монотонному времени
приёма; часы телефона не являются доверенным таймером. Отклонять дубликаты,
старые номера, неверные длины, NaN и значения вне диапазона. Не ставить команды
в длинную очередь; при просрочке последней валидной команды перейти к отпусканию.
Использовать защищённое сопряжение и явную привязку одного оператора. Обрыв приложения,
сворачивание и блокировка телефона должны приводить к истечению команды.

Регулятор силы: насыщение выхода, anti-windup, ограничение темпа и запрет
подтягивания после срабатывания защиты. Подбирать коэффициенты только на стенде
с моделированием податливости. Выходной энкодер определяет ход после проскальзывания
муфты; моторная обратная связь используется для диагностики. Не выполнять
автоматический поиск нуля натяжением повода. Ноль длины задаётся при механически
отключённой тяге, ноль силы проверяется без нагрузки.

Проводной удерживаемый разрешатель у оператора и ручной сброс дополняют красную
фиксируемую кнопку на корпусе. Снятие любого разрешения аппаратно обесточивает
муфты. Включение катушек, контактор и контроль освобождения требуют собственной
схемы; GPIO ESP32 и программный watchdog не заменяют эту цепь.
