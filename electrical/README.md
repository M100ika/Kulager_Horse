# electrical

Электроника модуля: плата управления на ESP32, CAN-шина к моторам, питание,
жгуты. Инструмент: KiCad 8 или новее (предпочтительно) либо EasyEDA, правила
в [CONTRIBUTING.md](../CONTRIBUTING.md#среда-разработки).

| Папка | Содержимое |
|---|---|
| `kicad/` | проект KiCad: схема (`.kicad_sch`) и плата (`.kicad_pcb`) |
| `easyeda/` | исходник проекта EasyEDA, если плата ведётся в EasyEDA |
| `libraries/` | собственные символы, посадочные места и 3D-модели компонентов |
| `harness/` | схемы жгутов, разъёмы, подключение моторов (питание + CAN) |
| `power/` | выбор батареи, расчёт тока и времени работы, питание моторов и логики, защита |
| `bom/` | спецификация компонентов для закупки |
| `fabrication/` | Gerber, сверловка, файлы для монтажа: всё, что отправляется на производство |

## Заметки

- В ESP32 встроен CAN-контроллер (TWAI), но нужен внешний трансивер на 3,3 В,
  например SN65HVD230. Шина CAN должна быть с терминаторами 120 Ом на обоих концах.
- Цепь аварийного стопа разрывает питание моторов аппаратно и не зависит от прошивки
  (см. `docs/safety/`).
- В `fabrication/` архив кладётся с ревизией в имени: `pcb-rA-gerber.zip`.
