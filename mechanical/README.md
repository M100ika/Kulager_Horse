# mechanical

Механика модуля: корпус, привод повода от двух AK80-64, крепление перед седлом.
Модели ведутся в любом CAD (SolidWorks, Fusion 360, FreeCAD), общий формат —
STEP: правила в [CONTRIBUTING.md](../CONTRIBUTING.md#формат-3d-моделей).
Текущие сборки сделаны в FreeCAD.

## Варианты установки на седло rB

Подготовлены [четыре 3D-шаблона на условном седле 17″](saddle-mounting-templates-rB.md):
передняя консоль, мост над лукой, боковые приводы и передний блок с задней батареей.
[Общая сборка FreeCAD](cad/assembly/saddle-templates/saddle-comparison-rB-templates.FCStd) ·
[Сравнительный PDF](drawings/saddle-templates/saddle-options-rB-templates.pdf).
Размеры седла приняты для компоновки; основной кандидат для макета — вариант 04.

## Компоновка rA

Создана [сборка модуля](cad/assembly/kulager-module-rA-concept.FCStd) с двумя
AK80-64, регулируемой рамой, барабанами, резервами муфт, батареи и электроники.
Описание, ограничения, расчёты и инструкция перестроения:
[concept-rA.md](concept-rA.md). [Габаритный PDF](drawings/kulager-layout-rA-concept.pdf).
Статус: концепт для стенда; интерфейсы покупных деталей и крепление к конкретному
седлу требуют деталировки. STL предназначены для проверки формы, не рабочего изделия.

| Папка | Содержимое |
|---|---|
| `cad/assembly/` | общая сборка модуля, исходник CAD |
| `cad/parts/` | собственные детали: корпус, барабаны или рычаги повода, кронштейны, крепление к седлу |
| `cad/vendor/` | STEP-модели покупных изделий: AK80-64, разъёмы, крепёж, подшипники |
| `drawings/` | чертежи в PDF для изготовления |
| `exports/` | STEP каждой детали и сборки (обновляется вместе с исходником), STL для 3D-печати |
| `calculations/` | расчёты: момент и натяжение повода, передаточное отношение, прочность, масса |

## Правила

- Имя файла детали: `kebab-case`, например `rein-drum-left.FCStd`.
- Покупные модели не редактируются, только подключаются в сборку.
- Выходные файлы в `exports/` и `drawings/` содержат ревизию в имени:
  `housing-rA.step`, `housing-rA.pdf`.
- `.FCStd` — бинарный файл, при слиянии git его не объединит. Над одним файлом
  одновременно работает один человек.
